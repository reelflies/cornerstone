# Guarded paths (W0-13). A PR that changes, adds, deletes or renames any path below needs an
# rf/safety sign-off on its head sha as well as the usual ones, and scripts/merge.sh refuses it
# without one. docs/guardrails.md explains the rules.
#
# One repo-relative path per line. A trailing slash guards everything under that folder. `*`
# matches within one path segment, and a pattern that matches a folder guards what is in it.
# Matching ignores case, as the Mac's file system does. This file is itself guarded, and
# merge.sh runs only with origin/master's copy of it and of the code that reads it, so a PR
# can't unguard itself. docs/guardrails.md, "What isn't guarded", lists what is left open on
# purpose.
